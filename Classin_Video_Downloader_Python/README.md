# ClassIn 视频下载器

一个用于 **批量下载 ClassIn 课堂录播视频** 的桌面工具，带图形界面，支持导入课程数据、保存配置、自动检测浏览器并自动下载匹配驱动。

## 功能特性

- 图形界面操作，适合日常直接使用
- 支持导入 `CSV / XLSX / XLS` 课程数据
- 支持粘贴 Cookie 登录态进行下载
- 自动检测本机浏览器（优先 Edge，其次 Chrome/Chromium）
- 运行时可通过 `webdriver-manager` 自动获取匹配驱动
- 支持批量任务列表、进度显示、日志输出
- 支持多线程并发下载（1-8线程可配置）
- 支持暂停/继续/停止下载
- 下载失败自动重试（最多3次）
- 自动获取 Cookie（登录后自动保存）
- 支持打包为 `.exe`

### 新增功能（v0.3.0）

- **断点续传**：支持中断后继续下载，避免重复下载
- **Cookie验证**：一键验证Cookie是否有效
- **下载速度限制**：可限制单个视频下载速度（1/2/5/10 MB/s）
- **跳过已下载文件**：自动跳过已存在的文件
- **下载完成操作**：支持下载完成后关机/休眠/关闭程序
- **任务排序筛选**：按班级ID、课堂ID、开课时间、状态排序和筛选
- **日志导出**：将下载日志导出为文本文件
- **输入验证**：下载前自动验证配置有效性
- **系统通知**：下载完成时显示系统通知

## 文件夹结构说明

下载的视频会按照以下结构组织：

```
保存目录/
├── {首次开课日期}_{班级名称}/          # 一级目录：班级
│   ├── {开课时间}_{课堂名称}/          # 二级目录：课堂
│   │   ├── 2026-03-20_课程名_录制方式_片段名.mp4
│   │   ├── 2026-03-20_课程名_录制方式_片段名_1.mp4
│   │   └── ...
│   └── {开课时间}_{课堂名称}/
│       └── ...
└── ...
```

**命名规则：**
- **一级目录**：`{该班级首次开课日期}_{班级名称}`（如 `2026-03-20_示例班级A`）
- **二级目录**：`{课堂开课时间}_{课堂名称}`（如 `2026-03-20_19-00_示例课堂A`）
- **视频文件**：`{录制日期}_{课程名}_{录制方式}_{片段名}.mp4`

## 使用方式

### 1. 准备课程数据

![课堂管理截图](./image/课堂管理截图.png)

从 ClassIn 后台导出课程统计数据，支持以下格式：
- `.csv`
- `.xlsx`
- `.xls`

**必需字段：**
- `课堂ID`
- `班级ID`
- `课堂名称`
- `班级名称`
- `开课时间`
- `创建时间`

### 2. 启动程序

```bash
python gui.py
```

### 3. 配置下载参数

在界面中填写或选择：
- **浏览器驱动路径**：可留空，程序自动处理
- **视频保存目录**：选择视频保存位置
- **数据文件路径**：导入课程数据文件
- **Cookie**：粘贴登录态 Cookie
- **下载线程数**：1-8，默认4
- **速度限制**：限制单个视频下载速度
- **完成操作**：下载全部完成后执行的操作
- **跳过已下载文件**：勾选后自动跳过已存在的文件

### 4. 获取 Cookie

方式一：点击"获取 Cookie"按钮，程序会自动打开浏览器，登录后自动保存

方式二：手动从浏览器开发者工具复制 Cookie 粘贴到输入框

> 注意：Cookie 有时效，过期后需要重新获取。可以点击"验证 Cookie"按钮检查Cookie是否有效。

### 5. 管理任务列表

- **导入 CSV/XLSX**：从文件导入课程数据
- **新增行**：手动添加任务
- **编辑行**：修改选中任务
- **删除行**：删除选中任务
- **排序**：按班级ID、课堂ID、开课时间、状态排序
- **筛选**：按状态筛选任务（待下载/下载中/已完成/失败）

### 6. 开始下载

点击"开始下载"，程序会：
1. 检测可用浏览器
2. 自动准备驱动
3. 加载课程数据
4. 逐条获取录播地址
5. 多线程并发下载视频到指定目录

**控制按钮：**
- **暂停/继续**：暂停或继续下载
- **停止**：终止下载任务

**下载完成操作：**
- 无操作：下载完成后不做任何操作
- 关闭程序：下载完成后自动关闭程序
- 休眠电脑：下载完成后电脑进入休眠状态
- 关机：下载完成后60秒自动关机（会显示提示）

## 配置文件说明

程序会自动生成 `config.json` 保存配置：

```json
{
  "driver_path": "",
  "save_dir": "D:\\Videos",
  "csv_file": "C:\\path\\to\\courses.csv",
  "cookie": "your_cookie_here",
  "max_workers": "4",
  "speed_limit": "不限制",
  "finish_action": "无操作",
  "skip_existing": true
}
```

**配置项说明：**
- `speed_limit`：下载速度限制，可选值：`不限制`、`1 MB/s`、`2 MB/s`、`5 MB/s`、`10 MB/s`
- `finish_action`：下载完成后的操作，可选值：`无操作`、`关闭程序`、`休眠电脑`、`关机`
- `skip_existing`：是否跳过已存在的文件，`true`跳过，`false`重新下载

## 常见问题

### 1）找不到浏览器
请确认本机已安装 Edge、Chrome 或 Chromium。

### 2）Cookie 无效
请重新登录后台并复制最新 Cookie。

### 3）下载失败
常见原因：
- Cookie 过期
- 课堂页面结构变化
- 网络波动
- 某条视频下载链接失效

### 4）驱动相关报错
程序默认会尝试自动处理驱动；如果自动获取失败，再手动指定驱动路径。
